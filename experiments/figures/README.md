# Рисунки вычислительного эксперимента

- `mixing.png`: ансамблевая разность плотностей и её абсолютное значение; полоса показывает ±1 SD по 12 начальным состояниям.
- `fields_periodic.png`, `fields_reflecting.png`: плотность (верхний ряд) и модуль скорости с её направлением (нижний ряд), seed=2026, t=0,120,800.
- `observables.png`: CV плотности и RMS макроскопической скорости для seed=2026.

Поля усредняются по блокам 8 × 8. Карты двух типов границ имеют одинаковые шкалы:
плотность от 0 до 2.4 частиц на узел; скорость от 0 до 1 узла за шаг.
На картах ось y направлена вверх. Численные данные и параметры находятся в соседних папках.
